#### 1.1.1 后端文件逐一详解

| 层级 | 文件夹/文件名 | 命名含义 | 功能详细说明 |
|------|---------------|----------|--------------|
| **根目录** | `pom.xml` | Project Object Model | Maven项目配置文件，定义所有依赖（SpringBoot、MyBatis、MySQL、Redis等）和构建配置 |
| **根目录** | `.gitignore` | Git Ignore | Git版本控制忽略文件配置 |
| **启动类** | `BackendApplication.java` | Backend(后端) + Application(应用) | SpringBoot主启动类，包含`@SpringBootApplication`注解，是整个后端应用的入口 |
| **config层** | `CorsConfig.java` | CORS(Cross-Origin Resource Sharing) + Config | 跨域配置类，使用`@CrossOrigin`或手动配置CorsFilter，允许前端跨域访问后端API |
| **config层** | `WebMvcConfig.java` | Web MVC + Config | Web MVC配置类，配置静态资源映射路径，实现`addResourceHandlers()`方法 |
| **exception层** | `BookNotEnoughException.java` | Book(图书) + NotEnough(不足) + Exception | 自定义异常类，当图书库存不足时抛出，继承RuntimeException |
| **exception层** | `OperationFailureException.java` | Operation(操作) + Failure(失败) + Exception | 自定义异常类，通用操作失败时抛出 |
| **exception层** | `GlobalExceptionHandler.java` | Global(全局) + Exception + Handler | 全局异常处理器，使用`@ControllerAdvice`和`@ExceptionHandler`统一捕获和处理所有异常 |
| **interceptor层** | `UserInterceptor.java` | User(用户) + Interceptor(拦截器) | 用户登录拦截器，实现`HandlerInterceptor`接口，在`preHandle()`中检查Token是否有效，未登录则阻止访问 |
| **interceptor层** | `ReaderInterceptor.java` | Reader(读者) + Interceptor | 读者权限拦截器，阻止普通用户访问管理员专属页面，检查用户的`isAdmin`字段 |
| **mapper层** | `UserMapper.java` | User + Mapper(映射器) | MyBatis Mapper接口，定义用户表的所有数据库操作方法：增删改查、按学号查询、分页查询等 |
| **mapper层** | `BookInfoMapper.java` | BookInfo(图书信息) + Mapper | 图书信息表Mapper接口，定义图书的增删改查、按条件搜索、按类型统计等方法 |
| **mapper层** | `BookTypeMapper.java` | BookType(图书类型) + Mapper | 图书类型表Mapper接口，定义图书类型的增删改查方法 |
| **mapper层** | `BorrowMapper.java` | Borrow(借阅) + Mapper | 借阅记录表Mapper接口，定义借阅记录的增删改查、分页查询、条件筛选等方法 |
| **mapper层** | `MessageMapper.java` | Message(消息) + Mapper | 消息表Mapper接口，定义站内消息的增删改查方法 |
| **mapper层** | `BookWishMapper.java` | BookWish(图书心愿) + Mapper | 求书心愿表Mapper接口，定义心愿的增删改查、按书名查询未满足心愿等方法 |
| **model层** | `User.java` | User(用户) | 用户实体类，对应user表，使用Lombok的@Data注解，包含userId、userName、studentId、userPassword、isAdmin、status、gender、openId、department、creditScore、todayAddScore、scoreUpdateDate等字段 |
| **model层** | `BookInfo.java` | BookInfo(图书信息) | 图书信息实体类，对应book_info表，包含bookId、bookName、bookAuthor、bookPrice、bookTypeId、bookDesc、isBorrowed、bookImage、bookCount、inventory、uploaderId、contactInfo等字段 |
| **model层** | `BookType.java` | BookType(图书类型) | 图书类型实体类，对应book_type表，包含bookTypeId、bookTypeName、bookTypeDesc等字段 |
| **model层** | `Borrow.java` | Borrow(借阅) | 借阅记录实体类，对应borrow表，包含borrowId、userId、bookId、borrowTime、returnTime、applyTime、borrowReason、state、returnMsg、secretCode、borrowDays等字段 |
| **model层** | `Message.java` | Message(消息) | 消息实体类，对应message表，包含messageId、userId、content、isRead、createTime等字段 |
| **model层** | `BookWish.java` | BookWish(图书心愿) | 求书心愿实体类，对应book_wish表，包含wishId、userId、userName、bookName、wishDesc、state、createTime、fulfillUserId等字段 |
| **service接口层** | `UserService.java` | User + Service(服务) | 用户业务接口，定义userLogin()、userRegister()、saveUser()、getUser()、removeUser()、setPassword()、queryUsers()、searchUsersByPage()、addUser()、deleteUser()、updateUser()等方法 |
| **service接口层** | `BookInfoService.java` | BookInfo + Service | 图书信息业务接口，定义getCount()、queryBookInfos()、searchBookInfosByPage()、addBookInfo()、deleteBookInfo()、updateBookInfo()、queryBookInfoById()等方法 |
| **service接口层** | `BookTypeService.java` | BookType + Service | 图书类型业务接口，定义getCount()、searchBookTypesByPage()、addBookType()、deleteBookType()、updateBookType()、queryBookTypes()等方法 |
| **service接口层** | `BorrowService.java` | Borrow + Service | 借阅业务接口，定义addBorrow()、auditBorrow()、verifyCode()、returnBook()、cancelBorrow()、nudgeUploader()、reportLoss()、urgeReturn()、bindWx()、unbindWx()、forcePenalize()等核心方法 |
| **service实现层** | `UserServiceImpl.java` | User + Service + Impl(实现) | 用户业务实现类，实现UserService接口的所有方法。核心逻辑：userLogin()校验学号密码、userRegister()查重学号、saveUser()将Token存入内存Map |
| **service实现层** | `BookInfoServiceImpl.java` | BookInfo + Service + Impl | 图书信息业务实现类。核心逻辑：addBookInfo()发布图书时自动加信用分（每天最多5分），并检查心愿墙是否有匹配的心愿进行通知 |
| **service实现层** | `BookTypeServiceImpl.java` | BookType + Service + Impl | 图书类型业务实现类。核心逻辑：deleteBookType()删除前检查是否有关联图书，有则拒绝删除返回-1 |
| **service实现层** | `BorrowServiceImpl.java` | Borrow + Service + Impl | 借阅业务核心实现类，包含所有借阅相关的复杂业务逻辑，是整个系统最核心的类。约460行代码，包含信用分管理、暗号验证、微信推送等所有核心功能 |
| **task层** | `BorrowTask.java` | Borrow + Task(任务) | 定时任务类，使用`@Scheduled(cron="0 */59 * * * ?")`每分钟执行一次。核心功能：1)扫描超时未审核/未交接的申请自动取消；2)扫描逾期借阅每日扣2信用分 |
| **utils层** | `R.java` | R(Result缩写) | 统一响应结果类，封装API返回数据。包含code(状态码)、msg(消息)、data(数据)三个核心字段，提供ok()、error()等静态工厂方法 |
| **utils层** | `PageUtils.java` | Page(分页) + Utils(工具) | 分页参数解析工具，解析前端传来的page和limit参数，计算begin偏移量 |
| **utils层** | `TokenProcessor.java` | Token(令牌) + Processor(处理器) | Token单例工具类。使用ConcurrentHashMap内存存储Token-User映射。generateToken()生成MD5+Base64编码的Token，saveUser()/getUser()/removeUser()管理用户会话 |
| **utils层** | `JsonUtil.java` | Json + Util | JSON序列化/反序列化工具类（使用较少） |
| **utils层** | `PathUtils.java` | Path(路径) + Utils | 文件路径处理工具类（用于上传文件） |
| **utils层** | `WechatPushUtils.java` | Wechat(微信) + Push(推送) + Utils | 微信推送工具类，集成WxPusher服务。pushMessage()方法通过HTTP请求发送消息到微信，支持HTML格式内容 |
| **utils层** | `BASE64Encoder.java` | BASE64 + Encoder(编码器) | Base64编码工具类（旧版本兼容） |
| **web控制层** | `UserController.java` | User + Controller(控制器) | 用户控制器，`@RequestMapping("/user")`。提供/login、/register、/logout、/queryUsersByPage、/addUser、/updateUser、/deleteUser、/setPassword等接口 |
| **web控制层** | `BookInfoController.java` | BookInfo + Controller | 图书信息控制器，`@RequestMapping("/bookInfo")`。提供/queryBookInfos、/addBookInfo、/updateBookInfo、/deleteBookInfo等接口 |
| **web控制层** | `BookTypeController.java` | BookType + Controller | 图书类型控制器，`@RequestMapping("/bookType")`。提供类型的增删改查接口 |
| **web控制层** | `BorrowController.java` | Borrow + Controller | 借阅控制器，`@RequestMapping("/borrow")`。提供/borrowBook、/audit、/verifyCode、/returnBook、/cancel、/nudge、/reportLoss、/urgeReturn、/bindWx、/unbindWx、/forcePenalize等核心接口 |
| **web控制层** | `MessageController.java` | Message + Controller | 消息控制器，`@RequestMapping("/message")`。提供消息列表、标记已读、删除等接口 |
| **web控制层** | `BookWishController.java` | BookWish + Controller | 求书心愿控制器，`@RequestMapping("/wish")`。提供/add、/list、/fulfill、/delete接口 |
| **web控制层** | `uploadController.java` | upload(上传) + Controller | 文件上传控制器，`@RequestMapping("/upload")`。处理图书封面图片上传，保存到static/files目录 |
| **resources/mapper** | `UserMapper.xml` | User + Mapper XML | MyBatis XML映射文件，定义user表的所有SQL语句。包含selectByUserName、insert、updateByPrimaryKeySelective、selectAllByLimit、selectCount等SQL |
| **resources/mapper** | `BookInfoMapper.xml` | BookInfo + Mapper XML | 图书信息SQL映射文件。核心SQL：selectBySearch实现同性发布优先排序、selectCountBySearch按条件统计 |
| **resources/mapper** | `BookTypeMapper.xml` | BookType + Mapper XML | 图书类型SQL映射文件 |
| **resources/mapper** | `BorrowMapper.xml` | Borrow + Mapper XML | 借阅记录SQL映射文件。核心SQL：selectAllByLimit实现多表关联查询（关联user和book_info表） |
| **resources/mapper** | `MessageMapper.xml` | Message + Mapper XML | 消息SQL映射文件 |
| **resources** | `application.yml` | Application YAML | SpringBoot配置文件。配置数据库连接（MySQL 8.0）、Redis连接、端口号（8080）、文件上传路径等 |
